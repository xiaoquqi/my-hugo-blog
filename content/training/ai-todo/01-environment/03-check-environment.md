第 3 步：提前检查 Python 和 Node.js。后续课程会用到这两个运行环境，提前确认好，避免运行项目时才发现缺失。

<!--more-->

打开 WorkBuddy 设置页，进入"运行环境检测"，检查 Python 和 Node.js 两项。

`[截图：设置 → 运行环境检测]`

提示缺失时，直接用页面提供的安装入口安装，装完重新检测一次，确认两项都正常。

### 如果安装失败

1. 记录完整错误提示。
2. 关闭并重新打开 WorkBuddy。
3. 再次执行环境检测。
4. 仍然失败，把错误信息交给 WorkBuddy，直接输入：

```text
Python 或 Node.js 环境安装失败。

请根据当前错误信息检查原因，
指导我完成安装，并在最后重新验证环境。
```

### 完成标准

进入下一节前确认：

- [ ] WorkBuddy 已安装并登录
- [ ] Python 检测正常
- [ ] Node.js 检测正常

三项都满足，环境安装就结束了，下一节过一遍 WorkBuddy 的界面。
